# Homebrew Druid Subclasses (D&D 2024 / 5.5e)

Six original Druid Circles built on the 2024 *Player's Handbook* chassis. Each
grants features at **Druid levels 3, 6, 10, and 14**, matching the official 2024
subclass cadence, and each includes an always-prepared **Circle spell list** that
grows at druid levels 3, 5, 7, and 9.

Every Circle here is a different answer to the question *"what does Wild Shape
become if it stops being about turning into a badger?"* — so each one rewrites,
reskins, or supercharges **Wild Shape** as its centerpiece. They are tuned to be
**strong**, for high-octane, anime- and myth-flavored tables. Dial the dice,
durations, and Wild Shape costs down a notch if your group runs lean.

## Design conventions used throughout

- **Spell save DC** and **spell attack bonus** always mean your Druid ones.
- **Wild Shape** is the 2024 class feature: a **Bonus Action** to transform, uses
  equal to the class table (**2 / 3 / 4** at levels 2 / 6 / 17), all expended uses
  returning on a **Long Rest** (one on a Short Rest). Unless a feature says
  otherwise, these Circles let you transform into their special form by spending a
  use of Wild Shape exactly as if it were a beast.
- **While transformed**, you keep your own mental ability scores, your skill and
  saving-throw proficiencies, and (unless noted) you can speak and concentrate.
- "Channel" features and bonus dice scale with your **Wisdom modifier** unless a
  number is given.
- Each Circle's level-3 Wild Shape form gives that form its own **Unarmored /
  natural Armor Class** while transformed (detailed in each file), so a Druid isn't
  paper-thin without armor. As with the Barbarian's Unarmored Defense, **you can use
  a shield and still gain the benefit.** The formula fits how the form survives:
  - **Agile dodgers** — Monkey King, Nika — use **10 + Dex + Wis**.
  - **The quaking juggernaut** — Sundering Earth — uses **10 + Con + Wis** (a
    Whitebeard/All Might–style "won't fall down" wall).
  - **Scaled / armored forms** use a fixed value + a stat: Titans **14 + Con**,
    Phoenix **13 + Wis**, Eastern Dragon **14 + Wis**.
- Features stack with the base class unless noted.
