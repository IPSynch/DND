# Homebrew D&D Compendium

A consolidated collection of homebrew content for Dungeons & Dragons (2024 rules):
custom **classes**, **subclasses** across many classes, and **species**.

## Structure

```
classes/           Homebrew base classes (+ supporting rules)
subclasses/        Homebrew subclasses, one folder per class
species/           Homebrew player species/lineages
BALANCE-REPORT.md  Game-balance ranking of the Sorcerer / Paladin / Visceralist subclasses
```

Homebrew base classes live in [`classes/`](./classes/).

## Species

Homebrew player species live in [`species/`](./species/) — 12 concept species plus a
trio of Elven lineages built for Elven Accuracy.

## Balance notes

All signature "*XXX die*" subclass features (Sorcerer, Paladin, Visceralist) open at
**1d8 at level 3**, scaling **1d8 → 2d8 → 3d8 → 4d8**. A full four-axis
(Offense / Defense / Healing / Utility) ranking of those subclasses lives in
[`BALANCE-REPORT.md`](./BALANCE-REPORT.md).
