# Name Bank — 10 male + 10 female per style

Two hundred worked names, built with the rules in `styles.md`. Use them three
ways: as a ready-made table resource, as calibration for what "done right" looks
like in each style, and as parts to cannibalize (swap a surname onto a different
given name and you have a cousin).

A few deliberately **echo the existing cast** — Luznura beside Luztherin,
Balaumerva beside Balaurung, Orinorra beside Origajima and Norra, Nyveth
Ashe'thi beside Merveya Ashe'kani. Those are drop-in relatives, rivals, or
order-mates. They're marked *(kin)*.

## Using the bank

- **Recombine freely.** The surnames are the valuable half. *Ambrose Tallyditch*,
  *Clemency Sallowmere*, *Maren Gravetender* are all legitimate — you're just
  picking a different member of the same parish.
- **The particles and clan-septs are cultural, not personal.** If you use
  `Vor'isk`, everyone from that clan carries `Vor'`. Same for `dan` versus `ap`
  in Harsh Particle — one particle per culture, consistently.
- **Layer across styles.** Take a Portmanteau-Root mononym and hang a
  Kenning-Byname on it: *Tsurumaat Gravetender*, *Balaumerva Frostgiven*. That
  cross-style pairing is where the best names in the existing cast come from.
