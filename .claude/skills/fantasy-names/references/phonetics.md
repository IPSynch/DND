## The sound-weight table

The fastest lever on a name's feel is which consonants you use. Pick the row
that matches the character, then build from it.

| Feel | Consonants | Vowels | Example | Styles |
|---|---|---|---|---|
| **Flowing / ancient / noble** | l, r, th, n, m, s, v | open a, e, i, o; no diphthongs | Thalion, Galadriel, Theramon | High Sindarin |
| **Rolling / dynastic** | m, n, r, d, ch, l (CV syllables only) | a, o, i | Chimamandara | Imperial Rolling |
| **Heavy / grim / cursed** | doubled ll, rr, ss, tt; g, d, b | short u, o, i | Dalligar, Dondarrion, Grimsditch | Anglo-Gothic, Portmanteau |
| **Ugly / rotten / bureaucratic** | clusters: gl, kt, br, sk, zh, pf, rst | short, clipped; consonant endings | Glokta, Skarn, Gorst | Harsh Particle |
| **Sharp / fast / modern** | k, t, d, s, n + one soft half | a, i; final -a | Norra Kaida, Vasha Kirin | Compact Duotone |
| **Alien / tribal** | x, tz, tl, q, k, glottal stops | a, o, e; clusters mid-word | Xochimeh, Tepoch'onnya | Apostrophe-Clan |
| **Plain / human / grounded** | ordinary English | ordinary English | Ravensway, Foldspire | Kenning-Byname |

**The mixing rule.** A name that uses exactly one row sounds monotone. The best
names in the corpus use one row for the given name and a different row for the
surname — Seshen (flowing) + Thalion (flowing but harder), Norra (sharp) + Kaida
(sharp-soft), Origajima (rolling) + Foldspire (plain). Pick two adjacent rows,
not two opposite ones, unless the contrast *is* the character.

## English compound kit (for Kenning-Byname & Anglo-Gothic)

ash · grim · crow · thorn · gallow · nettle · sorrow · wain · black · bell ·

frost · gild · rust · vow · lantern · cinder · brine · glass · tally

**Second halves — landforms & structures** (Anglo-Gothic surnames):
-ditch · -barrow · -moor · -hollow · -thwaite · -combe · -stoke · -worth ·
-wick · -marsh · -fen · -mire · -reach · -hallow · -church · -yard · -crook ·
-bourne · -shaw · -holt · -mere · -garth · -cote · -stead · -spire · -gate

**Second halves — deeds & states** (Kenning bynames):
-blessed · -breaker · -walker · -bearer · -fall · -wright · -kept · -shorn ·
-bound · -tender · -crowned · -sung · -touched · -given · -sworn · -taken ·
-lit · -fed · -read · -counted · -marked · -owed

**The linking trick.** When two halves collide badly, insert **-s-** or **-en-**:
Grim**s**ditch, Rav**ens**way, Ash**en**march. This is what real English
surnames do, and it's the single cheapest authenticity upgrade available.

## Repair techniques

When a name is *almost* right:

| Problem | Fix |
|---|---|
| Sounds like two words glued together | Change the vowel **at the seam**, not at the ends. `morde`+`kaisar` → Morde**ka**isa |
| Unpronounceable | Find the consonant cluster and insert a vowel into it |
| Too light, too pretty | Double a consonant (ll, rr, ss) or swap a liquid for a stop |
| Too heavy, clunky | Drop a consonant; open the final vowel to -a or -o |
| Too short for the role | Add a syllable to the *surname*, never the given name |
| Too long to say at the table | Cut the middle syllable; keep the first and last |
| Sounds generic | Replace the most ordinary syllable with a real foreign root that means something |
| Feels monocultural | Swap the ending for one from a different family in the bank above |
| Apostrophe doing nothing | Delete it, or move it to an actual syllable boundary |
| Two names don't sound like the same person | They shouldn't — that's the layering principle. But check they're *adjacent* rows in the sound-weight table, not opposite ones |
